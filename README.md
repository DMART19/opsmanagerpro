# Ops Command Center

Create a FEMA Warehouse Dashboard page that provides a clean operational overview.
Include the following layout:

Top summary cards showing:

Total Equipment (Available / Checked Out / Maintenance)

Upcoming Service / Calibration Due

Expiring Certifications

A horizontal “Today’s Tasks” list (audits, check-ins, events).

A table or card grid showing active check-outs (employee name, item, due date).

A right-side alert feed showing notifications (due-backs, expiring certs, upcoming audits).

Design this as the command center — managers see everything at a glance.
Use a 2-column responsive grid layout with cards, charts, and lists.
Add top navigation and breadcrumbs.
